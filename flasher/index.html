NSPanel Dom – web flasher

Flash the ready-made firmware to a Sonoff NSPanel (ESP32) from your browser (Chrome / Edge, USB serial adapter connected). Wi-Fi is set up after flashing through the on-screen / serial provisioning (Improv). Then add the device in Home Assistant (ESPHome integration).

Use Chrome or Edge on a desktop computer.

Status: experimental. The firmware binary is not published yet – see flasher/README.md. After flashing, upload the display file display/nspanel_dom.tft (HA button Upload TFT).

Polski: wgraj gotowy firmware z przeglądarki (Chrome/Edge, adapter USB-UART). Po wgraniu skonfiguruj Wi-Fi (Improv), dodaj urządzenie w HA i wgraj plik nspanel_dom.tft przyciskiem „Wgraj TFT”.
