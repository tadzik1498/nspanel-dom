# Translating

| Part | How | Languages now |
|---|---|---|
| Editor card (`dist/nspanel-dom-editor.js`) | Add an object to `TR` (copy the `en` block). Language follows HA, or `language:` in the card config. `node tests/smoke.js` checks key parity. | en, pl, de, uk |
| Panel on-screen texts (`esphome/nspanel_i18n.h`) | Add a table + macro `NSPANEL_LANG_xx`, set `language: xx` in the firmware substitutions. Check that the Nextion font has your glyphs (see BUILD-TFT.md). | pl (default), en |
| Texts generated by HA (`ha/nspanel_dom_ha.yaml`) | `input_select.nspanel_dom_language`; add a branch next to the existing `'en'` conditions. | pl, en |

## Intentionally NOT translated
- Entity ids/names created by the firmware (`Korytarz: zgaś po`, `Gong ...`, `Widoczna szerokość ekranu` ...)
  and the package script/field names (`tytul`, `tresc`, `dzwiek`). Other code (the editor card, the package
  regexes) looks them up by these names, so renaming them needs a coordinated change.
- Sound names (`Krótki`, `Podwójny`, `Kuranty`, ...) and levels (`Informacja`, `Ostrzeżenie`, `Alarm`):
  they are stored option values and are matched by the firmware.
- Code comments and the debug log are partly Polish (ASCII) – pull requests welcome.
